# Cairn

 Cairn is a simple landing page for a deployment monitoring tool. It helps development teams know whether a new release is safe after deployment.

 ## Features

 - Responsive design
- Dark theme
- Animated cairn illustration
- Mobile navigation menu
- Product features section
- Statistics section
- Call-to-action sections
- Smooth scrolling
- Reduced-motion support

 ## Technologies Used

 - HTML5
- CSS3
- JavaScript
- Google Fonts

 ## Files

```
cairn/
├── index.html
├── styles.css
└── README.md
```

 ## How to Run

 1. Download or clone the project.
2. Open `index.html` in your browser.

 That's it — no installation or build process is required.

 ## Design

 The website uses:

 - **Fraunces** for headings
- **IBM Plex Sans** for normal text
- **IBM Plex Mono** for technical text
- Dark gray background
- Green and sandstone accent colors

 ## Responsive Design

 The website works on:

 - Desktop
- Tablet
- Mobile

 The navigation changes to a mobile menu on smaller screens.

 ## Customization

 You can change the colors, fonts, spacing, and layout in `styles.css`.

 The main colors are defined at the top of the CSS file using variables such as:

```
--bg
--text
--moss
--sandstone
```
